# LevelForge — 专业游戏关卡白盒搭建与 3D/2D 空间分析工作台 (Walkthrough)

> **项目归档与启动路径**：`E:\AI Project\Level Builder`  
> **在线运行地址**：`http://localhost:5173/`（运行 `npm start`）

---

## 本次升级核心内容总览

### 1. 同时支持 3D 游戏设计与 2D 游戏设计 (`3D` / `2D 横版卷轴` / `2D 俯视地牢`)
* **顶部一键维度模式切换器 (`.dim-mode-bar`)**：
  * **🧊 `3D 立体关卡`**：适用于 FPS / TPS / 3D 动作 / 魂系箱庭，三视口联动（3D + 2D 俯视 + 2D 断面）。
  * **🍄 `2D 横版卷轴 (Side-Scroller / Metroidvania)`**：
    * 断面剖析图 $A\text{—}A'$ 自动沿 $X$ 轴对齐，并升级为**全交互式 2D 横版关卡主编辑器**（支持在 2D 横版视口直接左键拉框生成平台/斜坡/阶梯、上下左右拖拽移动、拖拽左右边缘调宽、拖拽顶边调高、直接放置 POI 与拉取跳跃抛物线）。
    * 新增 **`▲ 单向可穿透跳台 (one_way_platform)`** 语义类型，支持玩家从下方跳穿跃上平台，或在实机漫游中按 `S + Space` 下穿跳台。
    * 实机漫游 (`Tab`) 自动切换为 **2D 横版卷轴物理与正交跟拍相机 (`side_2d`)**，支持 `A / D` 左右移动与 `Space` 二段跳。
  * **🗡️ `2D 俯视地牢 (Top-Down RPG / Roguelike)`**：
    * 以 2D 俯视蓝图为主画布，实机漫游自动切换为 `W / A / S / D` 八向俯视移动与高空俯拍镜头。

### 2. 物体身份与设计思路备注系统 (`📝 一眼点击查看这是什么东西和设计思路`)
* **视口左下角浮动「物体身份与设计思路卡」(`#floating-note-card`)**：
  * 在 **3D 视口**、**2D 俯视图** 或 **2D 横版/断面图** 中点击任意白盒体块 (`Block`) 或标记点 (`POI`)，视口左下角立即弹出浮动解析卡片，直观展示：
    * **这是什么物体**：名称、功能语义标签、尺寸规格与所在楼层。
    * **🏷️ 9 大专业关卡设计定位预设标签 (`DESIGN_TAG_PRESETS`)**：支持一键点击打标并自动填入设计思路模板（`🚪 视觉引导门框`、`🛡️ 安全喘息掩体`、`⚠️ 高危交火暴露区`、`🎯 制高点压制位`、`🔄 魂系捷径单向门`、`🔑 钥匙/机关锁控`、`🍄 跳跃技巧考验`、`🎁 隐藏奖励诱导`、`🚩 阶段存档锚点`）。
    * **💡 核心设计思路 (`notes`)** 与 **⚙️ 玩法机制提示 (`mechanicsTip`)**：支持所见即所得实时编辑。
    * **🔑 机关/锁钥联动绑定 (`linkedId`)**：可将任意开关/钥匙/触发区绑定到目标锁门/升降桥/Boss，并在 2D 与 3D 视口中实时绘制紫色机关联动弧线。
* **视口内直接显示备注气泡 (`📝 设计思路气泡/机关线`)**：
  * 在 2D 俯视图与 2D 横版/断面图中，带有备注或设计定位的物体会自动渲染黄色 `📝 [定位标签]` 徽章，无需打开层层菜单即可一眼看清关卡各区域的策划意图。

### 3. 按游戏品类归类的常见房间快速生成模板库 (`src/core/room-templates.ts`)
在顶部模板下拉框以及右侧边栏 **「🏗️ 房间库/宏/AI」** 标签页中，按 **6 大游戏品类 (`ROOM_CATEGORIES`)** 收录了 **11 套** 带完整设计思路备注的经典房间模板，每套均支持 **「➕ 拼接追加到当前关卡」** 或 **「📂 设为独立新场景」**。
